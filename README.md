# 枢纽 · 统一办公平台 Agent

面向企业团队的 AI 原生统一办公与管理平台。系统以“目标 → 项目 → 风险/问题 → 决策 → 行动 → 证据”为主线，让网页、飞书、钉钉、企业微信及后续自建客户端共享同一业务事实、权限和审计内核。

当前开发版本为 `0.14.0-work-command-center`：产品第一入口已调整为“持久主对话 + 实时任务发布栏”。主 Agent 基于权限化业务上下文和声明式 Skill/Tool 原生理解目标，可拆分任务包、定向分派或开放承接，并让成员实时观察和推进个人任务；服务端不使用关键词或固定 Python/TypeScript 业务路由。`0.13.0` 的经营中枢与企业微信轻处置能力继续保留。真实 IdP、三平台测试企业、实际灾备/密钥轮换演练和四周真实团队试点仍需要企业外部环境，因此不能视为完整生产发布。

这是一个公开的工程源码快照，不代表生产就绪或已完成企业外部验收。公开仓库包含通用源码、测试、设计文档、项目管理账本和脱敏交接材料；企业环境配置、真实部署证据和运行产物不纳入仓库。

## 已实现

- Next.js 响应式企业工作台和交付指挥舱。
- 以主工作对话为第一入口的网页工作指挥中枢，同屏提供“我的、待承接、我发布”实时任务栏。
- LLM 原生 Skill/Tool 路由；可用工具先按身份、权限、渠道和风险过滤，所有业务副作用只通过 Tool Registry。
- 任务使命与可验收任务包、定向分派、开放承接、版本抢占、状态机、阻塞原因和完成证据门禁。
- 独立“Agent 开发”模块：需求先转换并留档为 `project-to-act` 五份文档，再保存主要版本 Git diff、功能清单和版本化功能测试，材料不完整时服务端拒绝交付。
- 可恢复 SSE 任务事件流、每人唯一活动主会话、持久消息与实际 Skill/Tool 路线回执。
- 目标、项目、里程碑、任务、风险、问题、决策和行动项领域模型。
- 风险登记、管理决策、行动下达、结果证据和任务状态推进的网页闭环。
- `/api/v1` Zod 输入契约、权限上下文和安全错误响应。
- PostgreSQL Schema、强制 RLS、持久化仓储；无数据库配置时使用开发内存仓储。
- Outbox/Inbox、审计脱敏、连接器端口和模型网关基础设施。
- 飞书长连接/HTTP、钉钉 Stream/加密 HTTP、企业微信 HTTPS 回调的统一事件适配。
- 三平台签名验真、AES 解密、时间窗、防重放、身份重解析、消息/卡片、回执、限流重试与全局通知去重。
- 渠道内 R3 提案以 `proposal_hash` 和过期时间重新鉴权确认，R4 操作保持禁用。
- “系统与集成”响应式控制台，可安全显示渠道是否已配置而不暴露任何凭据。
- 版本化流程定义与运行实例锁版，并支持并行会/或签、驳回、委托、加签、撤回、SLA 超时升级和高风险职责分离。
- Agent 审批预审与会议准备均为只读建议；正式审批、会议纪要确认及决定/行动沉淀由明确的人执行。
- 文档版本、数据分级、检索前过滤、返回前二次校验、可核验引用与不可信内容边界。
- 战略主题、OKR/KPI 分离、指标口径与来源、项目组合、经营复盘、事实/推断/决定分层。
- RACI 唯一负责人与容量规划；人才 Agent 只整理明确可见的证据，禁止评分、排名、雇佣建议和监控式代理指标。
- 企业 OIDC Authorization Code + PKCE、签名会话、显式主体映射与会话宽限轮换；生产默认拒绝演示身份。
- 存活/就绪分离，覆盖数据库、模型、受管 Secret、OTLP、WAF、分布式限流、备份和启用连接器的生产门禁。
- 受管 Secret 引用解析、结构化脱敏遥测、安全响应头、CSRF 来源校验和认证端点本地安全限流。
- AES-256-GCM 加密备份、校验恢复和显式恢复确认；Web/运维双镜像、Kubernetes 滚动发布、迁移与 15 分钟备份样例。
- 生产部署、SLO/事故、回滚/轮换及四周企业试点运行手册。
- 可安装桌面/移动 PWA、manifest/快捷入口、设备登记与撤销、最低版本和受管信任策略。
- Service Worker 只缓存静态资产与通用离线页，API、业务 HTML 和用户事实保持 network-only。
- Push 订阅服务端加密且锁屏只显示通用提示；Internal 离线草稿使用不可导出设备密钥加密并在 7 天后清理。
- 全部 tenant_id 数据表的强制 RLS 审计门禁，并以前向迁移修复历史 `role_permissions` 隔离缺口。
- 全部租户业务表由数据库触发器在同一事务内追加脱敏摘要审计；应用角色只能按租户追加/读取审计事件，不能修改或删除历史。
- 生产请求只把签名会话作为身份线索，每次都从权威数据库重新计算当前角色、权限和数据范围；人员停用或角色到期立即生效。
- 组织异动以独立审批驱动，执行时原子移交未关闭目标、项目、任务、风险、问题、行动、审批和责任，并在离职时同步撤销角色、委托、设备和外部身份。
- 项目立项字段、基线变更、管理例外队列、结项验收 Gate 和七天版本绑定补偿计划形成企业级项目治理闭环。
- 管理节奏实例与 AI 只读会前包、指标口径/新鲜度、项目组合情景唯一选定、企业事项 SLA/证据状态机和 AI 小样本治理。
- 企业微信管理动作使用接收人摘要、短时效提案哈希、当前身份/权限重算和业务对象/动作原子回写；卡片只作为同一事实的轻处置入口。
- 110 项设计需求都有精确测试引用和追踪 Gate；外部验收项保持显式待执行状态。
- 单元、迁移、仓储、API 和浏览器验收测试。

## 本地启动

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`：默认进入“工作对话”，可直接描述目标并观察任务拆包、分派、承接和个人任务状态；“Agent 开发”承载需求留档、主要版本、功能测试和交付门禁，“管理看板”“经营中枢”“项目与任务”“智能审批”“知识与会议”“目标与绩效”“权限与治理”“系统与集成”承载其他正式业务控制面。

生产构建默认要求已验证的企业身份提供者。仅在本机验收环境中可显式设置 `NEXUS_ALLOW_DEMO_IDENTITY=true`；真实部署必须保持关闭。

需要 PostgreSQL 持久化时，在受控的本地环境配置中提供 `DATABASE_URL`，然后执行：

```bash
npm run db:migrate
```

数据库或模型密钥不得写入源码、文档或提交记录。可复制 `.env.example` 了解变量名，但不要在其中填写真实凭据。
