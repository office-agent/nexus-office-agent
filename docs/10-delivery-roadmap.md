# 10 开发与交付路线

## 1. 实施策略

按“平台地基 → 纵向闭环 → 三渠道 → 管理扩展 → 自建客户端”推进。任何阶段都交付可运行、可测试、可审计的纵向结果，避免同时铺开所有菜单。

## 2. 阶段与 Gate

### M0 设计基线

交付：本文档集、需求追踪规则、领域边界、连接器能力矩阵、安全和验收计划。

Gate：文档相互一致，所有开发任务可追溯到需求 ID。

### M1 工程与平台地基

交付：

- 规范目录和模块边界。
- PostgreSQL Schema 与迁移。
- 租户、用户、组织、角色、策略和审计。
- 会话与开发用本地身份提供者。
- Outbox/Inbox、Job Worker、统一错误和 Trace。
- Fake Model、Fake Connector 与测试基座。

Gate：跨租户测试、迁移测试、审计完整性和 CI 通过。

### M2 管理纵向闭环

交付：

- 目标、项目、里程碑、任务。
- 风险、问题、决策、行动项。
- 网页工作台和管理视图。
- 领域事件和通知。

Gate：无 Agent、无外部平台时，网页可完成完整闭环。

### M3 Agent 平台

交付：

- AgentRun、上下文、检索、引用。
- Tool Registry、Policy、Proposal、Confirmation。
- 项目风险 Agent、会议 Agent。
- 模型路由、成本和评测。

Gate：恶意输入、越权和确认绕过测试通过；失败不产生副作用。

### M4 三平台连接器

交付：

- 飞书长连接与 HTTP Fixture。
- 钉钉 Stream 与 HTTP Fixture。
- 企业微信 HTTPS 回调、验签解密 Fixture。
- 统一身份、消息、卡片、事件、同步和通知路由。
- 管理后台连接状态与故障诊断。

Gate：所有协议契约测试通过；真实测试企业需要用户提供应用授权后执行外部验收。

### M5 流程、审批、会议和知识

交付：

- 持久化流程和审批。
- 会议纪要确认、决策和行动项。
- 文档索引、权限感知 RAG、版本和引用。
- Agent 审批预审和会议准备。

Gate：高风险确认、知识权限和运行中流程版本测试通过。

### M6 战略、经营、组织与人才

交付：

- 战略主题、OKR/KPI、指标树。
- 项目组合和经营驾驶舱。
- RACI、委托、资源容量。
- 绩效事实和人才发展基础，员工保护策略。

Gate：目标—项目—指标—贡献可追溯，敏感人才数据隔离通过。

### M7 生产化与试点

交付：

- SSO、生产 Secret Manager、备份与灾备。
- 监控告警、SLO、限流、WAF 和应急预案。
- 数据迁移和平台应用安装手册。
- 试点运营、培训和反馈闭环。

Gate：AC-001 至 AC-010 全部具备新鲜证据。

### M8 自建平台客户端

在统一 BFF、领域内核和 Agent API 稳定后开发自建桌面/移动端。保留网页作为管理后台；客户端重点提供通知、快捷操作、离线草稿、设备策略和企业分发。

### M11 持久化执行纠偏

在继续扩展客户端和更多管理模块前，先完成：完整 Inbox 信封、租约化 Inbox/Agent/Outbox Worker、异步 Agent 工具任务、崩溃幂等恢复、真实 Worker 心跳就绪、生产演示事实清理以及行为证据 Gate。

Gate：`DR-001` 至 `DR-014` 的 PostgreSQL 集成旅程、生产构建、同版本容器与 Kubernetes Worker 拓扑全部有新鲜证据；该 Gate 通过仍不替代真实企业外部验收。

## 3. 开发优先级

P0：身份、租户、权限、审计、领域模型、纵向闭环、Agent 确认、连接器协议、安全测试。

P1：流程审批、会议知识、战略经营、通知路由、运营分析。

P2：低代码、插件市场、多 Agent 可视化编排、自建客户端增强能力。

## 4. 数据迁移和兼容

- 所有数据库变更通过前向迁移，生产迁移提供回滚或补偿方案。
- 领域事件和 API 版本化。
- 外部平台 ID 始终经映射，不写入核心业务主键。
- 现有 0.1.0 演示组件可逐步迁移视觉部分，但不保留硬编码演示状态作为业务实现。

## 5. 当前下一步

1. 以 [16 持久化执行设计](./16-durable-runtime.md) 为 M11 唯一实现契约。
2. 完成 expand 迁移、通用租约仓储和 Worker 运行器。
3. 接通 Webhook → Inbox → 卡片确认 → Agent Job → 领域写 → Outbox 的真实链路。
4. 清除生产静态演示事实并以真实心跳、遥测和行为旅程强化 Readiness/Gate。
5. 完成自动化、容器、运行旅程和项目账本验收后，再进入自建平台客户端扩展。

## 6. 外部依赖

真实平台验收需要各平台测试企业中的自建应用和管理员授权。凭据只能通过本地受控配置或部署 Secret Manager 录入，不能通过对话提交。
